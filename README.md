# Sofia Barnes — Shopify Virtual Assistant

A responsive portfolio website built with Next.js App Router, TypeScript, Tailwind CSS and Lucide React.

## Run locally
```bash
npm install
npm run dev
```

## Before publishing
- Replace `YOUR_EMAIL@example.com` in `app/page.tsx` with your professional email.
- Replace the LinkedIn placeholder with your profile URL, or remove that link.
- Update `metadataBase` in `app/layout.tsx` to the deployed domain.
- Review the service list and sample projects so they accurately represent your offer.
- The contact form opens a pre-filled email draft; it is not a server-backed form.

Sample portfolio visuals are practice demonstrations, not claimed client work. No client logos, testimonials, credentials, or performance statistics are fabricated.
